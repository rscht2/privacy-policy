Política de Privacidad

Última actualización: 7 de junio de 2026

Esta Política de Privacidad describe cómo Rokola Admin recopila, utiliza y protege su información cuando utiliza nuestra aplicación móvil.

1. Información que Recopilamos

La aplicación Rokola Admin está diseñada para ser una herramienta de gestión administrativa. Recopilamos la mínima información necesaria para su funcionamiento:

  • Configuración del Servidor: Almacenamos la URL del servidor al que se conecta la aplicación para gestionar la Rokola.
  • Identificación del Establecimiento: Almacenamos el nombre del establecimiento configurado por el administrador.

2. Uso de Permisos

Para proporcionar sus funciones, la aplicación requiere los siguientes permisos:

  • Cámara: Utilizada exclusivamente para escanear códigos QR que contienen la configuración de conexión al servidor. No capturamos ni almacenamos fotos o videos.
  • Internet: Necesario para comunicarse con el servidor de la Rokola y realizar las tareas de administración.
  • Estado de Red: Utilizado para verificar si el dispositivo tiene conexión antes de intentar realizar operaciones.

3. Seguridad de los Datos

Nos comprometemos a proteger su información. La configuración almacenada se guarda localmente en el dispositivo y solo se utiliza para la comunicación directa con el servidor que usted mismo ha configurado.

4. Cambios en esta Política

Podemos actualizar nuestra Política de Privacidad periódicamente. Se le notificará de cualquier cambio publicando la nueva Política de Privacidad en esta página.

5. Contacto

Si tiene alguna pregunta sobre esta Política de Privacidad, puede contactarnos a través de los canales oficiales de soporte de Rokola.
