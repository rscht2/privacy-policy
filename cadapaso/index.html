Política de Privacidad

Cada Paso — Aplicación de consulta de guías para equipos biomédicos

Última actualización: marzo 2026

1. Información general

MedGuide es una aplicación Android diseñada para que operadores, auxiliares de enfermería y personal técnico consulten guías paso a paso para el manejo de equipos biomédicos. La app es de solo lectura: los usuarios no crean ni modifican contenido.

Sin registro de usuarios: Cada Paso no requiere crear una cuenta, iniciar sesión ni proporcionar ningún dato personal para su uso.

2. Datos que recopilamos

Cada Paso no recopila ningún dato personal de sus usuarios.

La aplicación únicamente realiza las siguientes operaciones de red:

OperaciónFinalidadDato transmitido
Consulta a Firebase Firestore Obtener lista de equipos y guías Ningún dato personal — solo lectura de contenido
Descarga de imágenes Mostrar fotos de los pasos de cada guía Ningún dato personal — solo descarga de imágenes

No se recopilan datos de ubicación, identidad, contactos, historial de uso, identificadores de dispositivo ni ningún otro dato personal.

3. Permisos de la aplicación

Cada Paso solicita únicamente el siguiente permiso:

  • INTERNET: necesario para descargar el contenido de las guías (equipos, pasos e imágenes) desde Firebase. Sin este permiso la app solo puede mostrar contenido previamente cacheado.

La app no solicita acceso a cámara, galería, micrófono, ubicación, contactos ni ningún otro recurso del dispositivo.

4. Caché local (modo sin conexión)

Para permitir el uso sin conexión a internet, Cada Paso almacena en el dispositivo una copia local de los datos de Firestore (hasta 50 MB) y de las imágenes descargadas (hasta 100 MB). Este contenido:

  • No contiene datos personales.
  • Es solo el contenido de las guías (texto e imágenes de equipos médicos).
  • Se almacena en el directorio de caché privado de la app y no es accesible por otras apps.
  • Se elimina automáticamente cuando el sistema necesita liberar espacio o al desinstalar la app.

5. Uso de servicios de terceros

La aplicación utiliza los siguientes servicios de Google / Firebase para obtener el contenido:

  • Firebase Firestore: base de datos en la nube (solo lectura desde la app).
  • Firebase Storage: almacenamiento de imágenes (solo descarga desde la app).

Estos servicios están sujetos a la Política de Privacidad de Google. No se comparten datos con ningún otro tercero.

6. Seguridad

  • Toda la comunicación con Firebase se realiza mediante HTTPS. La app bloquea explícitamente el tráfico HTTP.
  • Las reglas de seguridad de Firebase permiten únicamente lectura del contenido público de guías.
  • El backup automático de Android está deshabilitado.
  • El código de producción está ofuscado con R8/ProGuard.

7. Privacidad de menores

Cada Paso está destinada a profesionales de la salud y personal técnico. No está dirigida a menores de 13 años y no recopila conscientemente información de menores.

8. Cambios en esta política

Cualquier actualización a esta política se reflejará en esta página con una nueva fecha de actualización. Se recomienda revisarla periódicamente.
