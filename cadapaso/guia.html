👋 Que es Cada Paso?

Cada Paso es tu asistente digital para operar equipos biomedicos. Contiene guias paso a paso con imagenes reales para procedimientos y solucion de fallas, organizadas por equipo, marca y modelo.

📋 Procedimientos

Guias para operar el equipo correctamente paso a paso.

🔧 Fallas

Guias de diagnostico y solucion para problemas comunes.

📷 Imagenes reales

Cada paso puede incluir una foto del equipo real.

📶 Sin conexion

Las guias que ya consultaste estan disponibles sin internet.

Sin registro: no necesitas crear una cuenta ni iniciar sesion. Abre la app y empieza a consultar.

🔍 Buscar un equipo

La pantalla principal tiene tres filtros en cascada para encontrar el equipo que necesitas.

  1. Selecciona el Equipo — toca el primer campo y elige el tipo de equipo (ej: Electrocardiógrafo, Monitor de signos vitales, Desfibrilador).
  2. Selecciona la Marca — el segundo campo se activa mostrando solo las marcas disponibles para ese equipo (ej: EDAN, Mindray, Philips).
  3. Selecciona el Modelo — el tercer campo muestra los modelos disponibles para esa marca (ej: SE-3, SE-12, iMEC8).
  4. Las tarjetas de los equipos que coinciden aparecen debajo. Toca la tarjeta para ver sus guias.

📚 Ver las guias de un equipo

  1. Toca la tarjeta del equipo en los resultados de busqueda.
  2. Se abre la pantalla de guias con dos secciones:
    • Procedimientos — guias para operar el equipo.
    • Fallas — guias para diagnosticar y resolver problemas.
  3. Toca la guia que necesitas para abrirla.

Cada guia muestra su titulo, duracion estimada, nivel (Basico / Intermedio / Avanzado) y el numero de pasos.

Guias de Falla se muestran con fondo rojo para distinguirlas visualmente de los procedimientos normales.

👣 Seguir los pasos de una guia

Navegacion entre pasos

  • La barra de progreso en la parte superior muestra cuanto llevas completado.
  • El numero del paso actual y el total aparecen en la esquina superior derecha.
  • Toca "Siguiente →" para avanzar al siguiente paso.
  • Toca "← Anterior" para volver al paso previo.
  • En el ultimo paso, el boton cambia a "Finalizar" y te regresa a la lista de guias.

Contenido de cada paso

  • Titulo — accion principal a realizar.
  • Descripcion — detalle adicional cuando aplica.
  • Imagen — foto real del equipo. Puedes hacer zoom con los dedos.
  • Advertencia — banda roja con icono de alerta cuando el paso tiene un riesgo importante.
Presta atencion a las advertencias: los pasos con banda roja indican precauciones criticas de seguridad. Lelas antes de continuar.
Puedes ir y volver: no hay restriccion para navegar entre pasos en cualquier momento.

🔔 Solicitar una guia

Si no encuentras el equipo que necesitas, puedes enviar una solicitud directamente al tecnico biomedico para que lo registre.

Enviar una solicitud nueva

  1. Toca el icono + en la esquina superior derecha de la pantalla principal.
  2. Completa el nombre del equipo (obligatorio) y opcionalmente marca, modelo, area y descripcion.
  3. Si no recuerdas el nombre exacto, toca Camara o Galeria para adjuntar una foto del equipo.
  4. Toca "Enviar solicitud". El tecnico recibira tu solicitud de inmediato.
Tabulacion: usa el boton "Siguiente" del teclado para moverte entre los campos sin tocar la pantalla.

Ver el estado de tus solicitudes

  • Cuando el tecnico atiende tu solicitud y registra el equipo, aparece un icono de campana con un numero en la barra superior.
  • Toca la campana para ver el historial de tus solicitudes.
  • Las solicitudes atendidas muestran un boton "Buscar [nombre del equipo]" que te lleva directamente a los resultados en la pantalla principal.
Sin cuenta: tus solicitudes se identifican por el dispositivo, no por un usuario. Si cambias de dispositivo no podras ver el historial anterior.

📶 Uso sin conexion a internet

Cada Paso guarda automaticamente en tu dispositivo las guias que has consultado. La proxima vez que las abras, estaran disponibles aunque no tengas internet.

Que se guarda sin conexion?

  • La lista de equipos y sus datos.
  • El contenido de texto de todas las guias que hayas abierto.
  • Las imagenes de los pasos que hayas visualizado (hasta 100 MB).

Que NO esta disponible sin conexion?

  • Guias o equipos que nunca hayas abierto estando conectado.
  • Actualizaciones de contenido publicadas mientras estabas sin internet.
Recomendacion: si sabes que vas a trabajar en un area sin internet, abre las guias que necesitaras mientras tengas conexion para que queden guardadas.

❓ Preguntas frecuentes

No encuentro el equipo que busco

El equipo puede no estar registrado aun. Comunicate con el tecnico biomedico responsable para que lo agregue.

La guia no carga o muestra un error

  1. Verifica que tienes conexion a internet.
  2. Cierra la app completamente y vuelve a abrirla.
  3. Si el problema persiste, consulta con el tecnico biomedico.

Las imagenes no se ven

Las imagenes requieren conexion la primera vez. Una vez descargadas, quedan guardadas para uso sin conexion. Si nunca habias visto esa guia sin internet, las imagenes no estaran disponibles.

Puedo usar la app en una tablet?

Si. Cada Paso funciona en cualquier dispositivo Android con version 8.0 (Oreo) o superior, incluyendo tablets.

Como se actualiza el contenido?

El contenido se actualiza automaticamente desde la nube cada vez que abres la app con conexion. No necesitas actualizar la app para ver guias nuevas.

Necesito crear una cuenta?

No. Cada Paso no requiere registro ni inicio de sesion. Abre la app y consulta directamente.
