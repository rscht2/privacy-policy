👋 ¿Qué es Cada Paso?

Cada Paso es tu asistente digital para operar equipos biomédicos. Contiene guías paso a paso con imágenes reales para procedimientos y solución de fallas, organizadas por equipo, marca y modelo.

📋 Procedimientos

Guías para operar el equipo correctamente paso a paso.

🔧 Fallas

Guías de diagnóstico y solución para problemas comunes.

📷 Imágenes reales

Cada paso puede incluir una foto del equipo real.

📶 Modo sin conexión

Las guías que ya consultaste están disponibles sin internet.

ℹ️ Sin registro: no necesitas crear una cuenta ni iniciar sesión. Abre la app y empieza a consultar.

🔍 Buscar un equipo

La pantalla principal tiene tres filtros en cascada para encontrar el equipo que necesitas:

  1. Selecciona el Equipo — toca el primer campo y elige el tipo de equipo (ej: Electrocardiógrafo, Monitor de signos vitales, Desfibrilador). La lista se despliega con todos los equipos disponibles en orden alfabético.
  2. Selecciona la Marca — una vez elegido el equipo, el segundo campo se activa mostrando solo las marcas disponibles para ese equipo (ej: EDAN, Mindray, Philips).
  3. Selecciona el Modelo — el tercer campo muestra los modelos disponibles para esa marca (ej: SE-3, SE-12, iMEC8).
  4. Las tarjetas de los equipos que coinciden aparecen debajo de los filtros. Toca la tarjeta del equipo para ver sus guías.

📚 Ver las guías de un equipo

  1. Toca la tarjeta del equipo en los resultados de búsqueda.
  2. Se abre la pantalla de guías con dos secciones:
    • Procedimientos — guías para operar el equipo.
    • Fallas — guías para diagnosticar y resolver problemas.
  3. Toca la guía que necesitas para abrirla.

Cada guía muestra su título, duración estimada, nivel (Básico / Intermedio / Avanzado) y el número de pasos.

⚠️ Guías de Falla se muestran con fondo rojo para distinguirlas visualmente de los procedimientos normales.

👣 Seguir los pasos de una guía

Navegación entre pasos

  • La barra de progreso en la parte superior muestra cuánto llevas completado.
  • El encabezado indica "Paso X de Y" para que siempre sepas dónde estás.
  • Toca "Siguiente →" para avanzar al siguiente paso.
  • Toca "← Anterior" para volver al paso previo.
  • En el último paso, el botón cambia a "Finalizar ✓" y te regresa a la lista de guías.

Contenido de cada paso

  • Número del paso — círculo con el número en la parte superior.
  • Título — acción principal a realizar (ej: "Encender el equipo").
  • Descripción — detalle adicional cuando aplica.
  • Imagen — foto real del equipo mostrando el elemento del paso. Puedes hacer zoom con los dedos.
  • Advertencia — tarjeta roja con ícono ⚠️ cuando el paso tiene un riesgo o precaución importante.
⚠️ Presta atención a las advertencias: los pasos con tarjeta roja indican precauciones críticas de seguridad. Léelas antes de continuar.

Indicadores de progreso (puntos)

En la barra de navegación inferior verás puntos que representan los pasos. El punto más grande y de color es el paso actual. Si la guía tiene más de 7 pasos, se muestra "…" para indicar que hay más.

✅ Puedes ir y volver: no hay restricción para navegar entre pasos. Puedes revisar un paso anterior en cualquier momento sin perder tu posición.

📶 Uso sin conexión a internet

Cada Paso guarda automáticamente en tu dispositivo las guías que has consultado. La próxima vez que las abras, estarán disponibles aunque no tengas internet.

¿Qué se guarda sin conexión?

  • La lista de equipos y sus datos.
  • El contenido de texto de todas las guías que hayas abierto.
  • Las imágenes de los pasos que hayas visualizado (hasta 100 MB).

¿Qué NO está disponible sin conexión?

  • Guías o equipos que nunca hayas abierto estando conectado.
  • Actualizaciones de contenido publicadas mientras estabas sin internet.
ℹ️ Recomendación: si sabes que vas a trabajar en un área sin internet, abre las guías que necesitarás mientras tengas conexión para que queden guardadas.

❓ Preguntas frecuentes

No encuentro el equipo que busco

El equipo puede no estar registrado aún en el sistema. Comunícate con el técnico biomédico responsable para que lo agregue a la base de datos.

La guía no carga o muestra un error

  1. Verifica que tienes conexión a internet.
  2. Cierra la app completamente y vuelve a abrirla.
  3. Si el problema persiste, la guía puede haber sido eliminada o movida. Consulta con el técnico biomédico.

Las imágenes no se ven

Las imágenes requieren conexión a internet la primera vez que se cargan. Una vez descargadas, quedan guardadas para uso sin conexión. Si no tienes internet y nunca habías visto esa guía, las imágenes no estarán disponibles.

¿Puedo usar la app en una tablet?

Sí. Cada Paso funciona en cualquier dispositivo Android con versión 8.0 (Oreo) o superior, incluyendo tablets.

¿Cómo se actualiza el contenido?

El contenido se actualiza automáticamente desde la nube cada vez que abres la app con conexión a internet. No necesitas actualizar la app para ver guías nuevas.

¿Necesito crear una cuenta?

No. MedGuide no requiere registro ni inicio de sesión. Abre la app y consulta directamente las guías disponibles.
