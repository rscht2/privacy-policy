Política de Privacidad

Cada Paso — Aplicación de consulta de guías para equipos biomédicos

Última actualización: marzo 2026

1. Información general

Cada Paso es una aplicación Android diseñada para que operadores, auxiliares de enfermería y personal técnico consulten guías paso a paso para el manejo de equipos biomédicos. Adicionalmente, los usuarios pueden enviar solicitudes al técnico biomédico para registrar equipos que no estén disponibles aún.

Sin registro de usuarios: Cada Paso no requiere crear una cuenta ni iniciar sesión. Las solicitudes se identifican por el dispositivo de forma anónima.

2. Datos que recopilamos

La aplicación realiza las siguientes operaciones de red:

OperaciónFinalidadDato transmitido
Consulta a Firebase Firestore Obtener lista de equipos y guías Ningún dato personal — solo lectura de contenido
Descarga de imágenes Mostrar fotos de los pasos de cada guía Ningún dato personal — solo descarga de imágenes
Envío de solicitud de guía Notificar al técnico biomédico sobre un equipo no registrado Texto descriptivo del equipo, foto opcional, identificador anónimo del dispositivo (Android ID)
Subida de foto de solicitud Adjuntar imagen del equipo a la solicitud Imagen seleccionada por el usuario — sin metadatos de identidad

No se recopilan datos de ubicación, identidad personal, contactos ni historial de navegación. El identificador de dispositivo (Android ID) es anónimo y se usa únicamente para mostrar al usuario el estado de sus propias solicitudes.

3. Permisos de la aplicación

  • INTERNET: necesario para descargar guías y enviar solicitudes a Firebase.
  • CAMERA: opcional — solo se solicita si el usuario decide tomar una foto del equipo al enviar una solicitud. No se usa para ningún otro fin.
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE: opcional — solo se solicita si el usuario decide adjuntar una foto de la galería a una solicitud.

Los permisos de cámara y galería son opcionales. La app funciona completamente sin ellos.

4. Caché local (modo sin conexión)

Para permitir el uso sin conexión a internet, Cada Paso almacena en el dispositivo una copia local de los datos de Firestore (hasta 50 MB) y de las imágenes descargadas (hasta 100 MB). Este contenido:

  • No contiene datos personales.
  • Es solo el contenido de las guías (texto e imágenes de equipos médicos).
  • Se almacena en el directorio de caché privado de la app y no es accesible por otras apps.
  • Se elimina automáticamente cuando el sistema necesita liberar espacio o al desinstalar la app.

5. Solicitudes de guías

Cuando un usuario envía una solicitud de guía, se almacena en Firebase Firestore el siguiente contenido:

  • Nombre del equipo, marca, modelo, área y descripción proporcionados por el usuario.
  • Foto del equipo (opcional), almacenada en Firebase Storage.
  • Identificador anónimo del dispositivo (Android ID) para mostrar el estado de la solicitud al mismo usuario.
  • Fecha y hora de envío.

Esta información es visible únicamente para el técnico biomédico administrador del sistema. No se comparte con terceros. El usuario puede ver el estado de sus solicitudes desde la app.

6. Uso de servicios de terceros

La aplicación utiliza los siguientes servicios de Google / Firebase:

  • Firebase Firestore: base de datos en la nube (lectura de guías y gestión de solicitudes).
  • Firebase Storage: almacenamiento de imágenes de guías y fotos de solicitudes.

Estos servicios están sujetos a la Política de Privacidad de Google. No se comparten datos con ningún otro tercero.

7. Seguridad

  • Toda la comunicación con Firebase se realiza mediante HTTPS. La app bloquea explícitamente el tráfico HTTP.
  • Las reglas de seguridad de Firebase permiten escritura de solicitudes sin autenticación, pero solo el administrador puede leer y gestionar todas las solicitudes.
  • El backup automático de Android está deshabilitado.
  • El código de producción está ofuscado con R8/ProGuard.

8. Privacidad de menores

Cada Paso está destinada a profesionales de la salud y personal técnico. No está dirigida a menores de 13 años y no recopila conscientemente información de menores.
