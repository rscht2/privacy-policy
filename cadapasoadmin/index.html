Política de Privacidad

Cada Paso Admin — Aplicación de administración de guías biomédicas

Última actualización: marzo 2026

1. Información general

Cada Paso Admin es una aplicación Android de uso personal y exclusivo del técnico biomédico responsable del sistema. No está destinada al público general ni a múltiples usuarios. Esta política describe qué datos se procesan, con qué finalidad y cómo se protegen.

Uso restringido: el acceso a esta aplicación está limitado a una única cuenta de Google autorizada. Ningún otro usuario puede iniciar sesión ni acceder al contenido de administración.

2. Datos que recopilamos

DatoFinalidadAlmacenamiento
Correo electrónico (Google) Autenticación y control de acceso Firebase Authentication
Fotografías tomadas con la cámara Ilustrar pasos de guías de equipos médicos Firebase Storage (nube)
Imágenes seleccionadas de la galería Ilustrar pasos de guías de equipos médicos Firebase Storage (nube)
Datos de equipos y guías (texto) Contenido de la base de conocimiento biomédica Firebase Firestore (nube)

No se recopilan datos de ubicación, contactos, historial de navegación ni ningún otro dato personal más allá de los indicados.

3. Permisos de la aplicación

  • CAMERA: necesario para tomar fotografías de los pasos de cada guía directamente desde la app.
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE: necesario para seleccionar imágenes existentes en la galería del dispositivo.
  • INTERNET: necesario para sincronizar el contenido con Firebase (Firestore y Storage).

Ninguno de estos permisos se usa para fines distintos a los descritos. Las imágenes se comprimen y se suben directamente a Firebase Storage; no se almacenan copias locales permanentes en el dispositivo.

4. Uso de servicios de terceros

La aplicación utiliza los siguientes servicios de Google / Firebase:

  • Firebase Authentication: gestión del inicio de sesión con Google.
  • Firebase Firestore: base de datos en la nube para equipos y guías.
  • Firebase Storage: almacenamiento de imágenes de los pasos.

Estos servicios están sujetos a la Política de Privacidad de Google. No se comparten datos con ningún otro tercero.

5. Seguridad de los datos

  • Toda la comunicación con Firebase se realiza mediante HTTPS (TLS). La app bloquea explícitamente el tráfico HTTP.
  • Las reglas de seguridad de Firestore y Storage permiten escritura únicamente al usuario autenticado y autorizado.
  • El backup automático de Android está deshabilitado para evitar exposición de datos de sesión.
  • El código de producción está ofuscado con R8/ProGuard.

6. Retención y eliminación de datos

Los datos (equipos, guías, imágenes) permanecen en Firebase mientras el administrador no los elimine manualmente desde la aplicación. Al eliminar una guía o un paso, las imágenes asociadas se borran también de Firebase Storage.

Para eliminar completamente todos los datos, el administrador puede borrar el proyecto de Firebase desde la consola de Firebase.

7. Derechos del usuario

Como único usuario de esta aplicación, tienes control total sobre todos los datos: puedes crear, editar y eliminar cualquier contenido en cualquier momento desde la propia app.

8. Cambios en esta política

Cualquier actualización a esta política se reflejará en esta página con una nueva fecha de actualización. Se recomienda revisarla periódicamente.
